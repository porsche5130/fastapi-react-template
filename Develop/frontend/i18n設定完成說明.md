### 3. 配置 i18n

#### i18n 配置檔
- **檔案**: `src/i18n.ts`
- **功能**:
  - 自動偵測使用者語言
  - 預設語言：繁體中文 (zh-TW)
  - 支援語言：繁體中文 (zh-TW)、英文 (en)
  - 使用 localStorage 儲存語言偏好

#### 配置特性
```typescript
{
  fallbackLng: 'zh-TW',        // 預設語言
  lng: 'zh-TW',                 // 初始語言
  supportedLngs: ['zh-TW', 'en'], // 支援語言
  detection: {
    order: ['localStorage', 'navigator'],
    caches: ['localStorage'],
  }
}
```

## 📋 使用範例

### 在元件中使用 i18n

```typescript
import { useTranslation } from 'react-i18next';

const MyComponent: React.FC = () => {
  const { t, i18n } = useTranslation();

  return (
    <div>
      {/* 簡單文字 */}
      <h1>{t('common.systemName')}</h1>

      {/* 帶變數的文字 */}
      <p>{t('dashboard.rolesCount', { count: 5 })}</p>

      {/* 切換語言 */}
      <button onClick={() => i18n.changeLanguage('en')}>
        English
      </button>

      {/* 取得當前語言 */}
      <p>Current: {i18n.language}</p>
    </div>
  );
};
```

### 新增語系文字

編輯對應的語系檔案：
- 中文：`src/locales/zh-TW/translation.json`
- 英文：`src/locales/en/translation.json`

```json
{
  "yourSection": {
    "yourKey": "你的文字"
  }
}
```

然後在元件中使用：
```typescript
t('yourSection.yourKey')
```

## 📝 注意事項

1. **語言代碼**: 使用 `zh-TW` (繁體中文) 而非 `zh-CN` (簡體中文)
2. **預設語言**: 系統預設使用繁體中文
3. **localStorage Key**: 語言儲存在 `i18nextLng` key
4. **命名規範**: 語系 key 使用小駝峰命名法
5. **變數插值**: 使用 `{{variable}}` 格式
