## 已實作的 API 整合

### ✅ 系統 API
- `GET /api/system/profile` - 取得系統設定
- `GET /api/system/check` - 系統健康檢查

### ✅ 認證 API
- `POST /api/auth/login` - 使用者登入
- `GET /api/auth/me` - 取得使用者資訊
- `POST /api/auth/logout` - 使用者登出

## 狀態管理

### AuthContext
```typescript
{
  user: UserProfile | null           // 使用者資料
  isAuthenticated: boolean            // 登入狀態
  login: (token: string) => Promise   // 登入函式
  logout: () => Promise               // 登出函式
}
```

### SystemContext
```typescript
{
  systemProfile: SystemProfile | null // 系統設定
  isService: boolean                  // 服務狀態
  isLoading: boolean                  // 載入狀態
}
```
