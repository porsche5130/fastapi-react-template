## 選擇理由

### React + TypeScript
- React 生態系成熟，社群活躍
- TypeScript 提供型別安全，減少執行時錯誤
- 豐富的第三方套件支援

### Vite
- 極快的開發伺服器啟動速度
- HMR (Hot Module Replacement) 快速更新
- 原生 ES modules 支援
- 優異的生產環境建置效能

### Zustand
- API 簡潔直觀
- 無需 Provider 包裹
- TypeScript 支援良好
- 輕量級 (約 1KB)

### TanStack Query
- 自動快取管理
- 背景資料更新
- 樂觀更新支援
- 減少 boilerplate 程式碼

### shadcn/ui + Radix UI
- 基於 Radix UI，無障礙性最佳
- 元件直接複製到專案中，完全可控
- 使用 Tailwind CSS，高度可客製化
- TypeScript 支援完整

### React Hook Form + Zod
- 高效能（減少不必要的 re-render）
- TypeScript 原生支援
- Zod 提供執行時驗證與型別推導
- API 簡潔易用

### i18next
- 功能完整的國際化解決方案
- 支援動態語言切換
- 與後端語系檔案整合方便
- React 生態系標準選擇

### Tiptap
- 基於 ProseMirror，穩定可靠
- Headless 架構，高度可客製化
- 豐富的擴展功能（標題、列表、表格、圖片等）
- TypeScript 支援完整
- 與 React Hook Form 整合方便

## 與後端整合

### 後端共用資料目錄

前端透過 HTTP 存取後端的共用資料目錄：

| 資源類型 | 後端目錄 | URL 路徑 | 用途 |
|----------|----------|----------|------|
| 圖片資源 | `backend/sharedata/images/` | `/images/` | Logo、圖示、系統圖片、使用者上傳圖片 |
| 上傳檔案 | `backend/sharedata/uploads/` | `/uploads/` | PDD 文件、報告、使用者上傳檔案 |
| 語系檔案 | `backend/sharedata/locales/` | `/locales/{lang}/` | 多語系翻譯檔案（en, zh-TW, zh-CN） |

**參考文件**: `W:\P-PA6.4\系統設計\架構設計\後端架構\靜態資源與共用目錄.md`

### 語系檔案整合

i18next 設定從後端載入語系檔案：

```typescript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import Backend from 'i18next-http-backend';

i18n
  .use(Backend)
  .use(initReactI18next)
  .init({
    lng: 'zh-TW',
    fallbackLng: 'en',
    backend: {
      loadPath: '/locales/{{lng}}/{{ns}}.json'
    },
    ns: ['common', 'pdd', 'validation'],
    defaultNS: 'common'
  });
```

### Vite 開發環境代理設定

```typescript
// vite.config.ts
export default defineConfig({
  server: {
    port: 3000,
    proxy: {
      '/api': 'http://localhost:8000',
      '/images': 'http://localhost:8000',
      '/uploads': 'http://localhost:8000',
      '/locales': 'http://localhost:8000'
    }
  }
});
```
