## 目錄說明

### 1. images/ - 圖片資源

**用途**: 存放所有圖片相關檔案

| 檔案類型 | 範例 | 存取權限 |
|----------|------|----------|
| Logo | logo-main.svg, logo-icon.png | 公開讀取 |
| 圖示 | icon-download.svg, icon-upload.png | 公開讀取 |
| 系統圖片 | banner.jpg, placeholder.png | 公開讀取 |
| 使用者上傳圖片 | 20260118_a1b2c3d4.jpg | 需驗證 |

**支援格式**: PNG, JPG, JPEG, GIF, SVG, ICO

**檔案命名建議：**
- Logo: `logo-{variant}.{ext}`
- 圖示: `icon-{name}.{ext}`
- 上傳圖片: `{timestamp}_{uuid}.{ext}`

**檔案大小限制**: 5 MB

### 2. uploads/ - 上傳檔案

**用途**: 存放使用者上傳的各類檔案

| 檔案類型 | 範例 | 保留期限 |
|----------|------|----------|
| PDD 文件 | pdd_123_20260118.pdf | 永久 |
| Word 文件 | report_456_20260118.docx | 永久 |
| Excel 試算表 | data_789_20260118.xlsx | 永久 |
| 其他文件 | document_20260118.zip | 依需求 |

**支援格式**: PDF, DOCX, XLSX, ZIP 等

**檔案命名建議：**
- `{project_id}_{doc_type}_{timestamp}.{ext}`
- `{category}_{id}_{timestamp}.{ext}`

**檔案大小限制**: 50 MB

### 3. locales/ - 語系檔案

**用途**: 多語系支援的翻譯檔案

| 語系代碼 | 語言 | 檔案格式 |
|----------|------|----------|
| **en/** | English | JSON |
| **zh-TW/** | 繁體中文 | JSON |
| **zh-CN/** | 简体中文 | JSON |

**檔案命名：**
- 通用翻譯: `common.json`
- 模組翻譯: `{module}.json` (例: pdd.json, validation.json)

**語系檔案範例：**
```json
{
  "ui": {
    "buttons": {
      "submit": "提交",
      "cancel": "取消"
    }
  },
  "messages": {
    "success": "操作成功",
    "error": "操作失敗"
  }
}
```

## FastAPI 設定

### 靜態檔案掛載

```python
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles
from pathlib import Path

app = FastAPI()

# 共用資料目錄
SHAREDATA_DIR = Path(__file__).parent / "sharedata"

# 掛載靜態檔案
app.mount("/images", StaticFiles(directory=SHAREDATA_DIR / "images"), name="images")
app.mount("/uploads", StaticFiles(directory=SHAREDATA_DIR / "uploads"), name="uploads")
app.mount("/locales", StaticFiles(directory=SHAREDATA_DIR / "locales"), name="locales")
```

### URL 存取路徑

| 資源類型 | URL 路徑 | 範例 |
|----------|----------|------|
| 圖片 | `/images/` | `/images/logo-main.svg` |
| 上傳檔案 | `/uploads/` | `/uploads/pdd_123_20260118.pdf` |
| 語系檔 | `/locales/{lang}/` | `/locales/zh-TW/common.json` |

## 檔案上傳處理

### 上傳 API 端點範例

```python
from fastapi import UploadFile, File, HTTPException
from pathlib import Path
import uuid
from datetime import datetime

@app.post("/api/upload/image")
async def upload_image(file: UploadFile = File(...)):
    """上傳圖片"""
    # 檔案類型驗證
    allowed_types = {"image/png", "image/jpeg", "image/jpg", "image/gif", "image/svg+xml"}
    if file.content_type not in allowed_types:
        raise HTTPException(400, "不支援的檔案類型")

    # 檔案大小驗證（5MB）
    max_size = 5 * 1024 * 1024

    # 生成檔名
    timestamp = datetime.now().strftime("%Y%m%d%H%M%S")
    file_uuid = str(uuid.uuid4())[:8]
    ext = file.filename.split(".")[-1]
    filename = f"{timestamp}_{file_uuid}.{ext}"

    # 儲存路徑
    save_path = SHAREDATA_DIR / "images" / filename

    # 儲存檔案
    with open(save_path, "wb") as f:
        content = await file.read()
        if len(content) > max_size:
            raise HTTPException(400, "檔案過大")
        f.write(content)

    return {
        "filename": filename,
        "url": f"/images/{filename}",
        "size": len(content)
    }

@app.post("/api/upload/document")
async def upload_document(
    file: UploadFile = File(...),
    project_id: str = None
):
    """上傳文件"""
    # 檔案類型驗證
    allowed_types = {
        "application/pdf",
        "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
        "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
    }
    if file.content_type not in allowed_types:
        raise HTTPException(400, "不支援的檔案類型")

    # 檔案大小驗證（50MB）
    max_size = 50 * 1024 * 1024

    # 生成檔名
    timestamp = datetime.now().strftime("%Y%m%d%H%M%S")
    ext = file.filename.split(".")[-1]
    filename = f"{project_id}_{timestamp}.{ext}" if project_id else f"doc_{timestamp}.{ext}"

    # 儲存路徑
    save_path = SHAREDATA_DIR / "uploads" / filename

    # 儲存檔案
    with open(save_path, "wb") as f:
        content = await file.read()
        if len(content) > max_size:
            raise HTTPException(400, "檔案過大")
        f.write(content)

    return {
        "filename": filename,
        "url": f"/uploads/{filename}",
        "size": len(content)
    }
```

## 安全性考量

### 1. 檔案類型驗證

- 驗證 MIME type
- 檢查副檔名
- 掃描惡意檔案（可選）

### 2. 檔案大小限制

- 圖片: 5 MB
- 文件: 50 MB
- 防止 DoS 攻擊

### 3. 存取權限控制

| 目錄 | 存取方式 | 備註 |
|------|----------|------|
| `/images/` | 依檔案類型區分 | 系統圖片公開，使用者上傳需驗證 |
| `/uploads/` | 需驗證 | 專案文件需驗證身份 |
| `/locales/` | 公開讀取 | 語系檔案公開存取 |

### 4. 檔案管理

- **定期備份**: 重要檔案定期備份到外部儲存
- **日誌記錄**: 記錄所有上傳和刪除操作
- **容量監控**: 監控磁碟使用量

## 前後端互動

### 前端上傳範例

```javascript
// 上傳圖片
async function uploadImage(file) {
  const formData = new FormData();
  formData.append('file', file);

  const response = await fetch('/api/upload/image', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`
    },
    body: formData
  });

  return await response.json();
}

// 上傳文件
async function uploadDocument(file, projectId) {
  const formData = new FormData();
  formData.append('file', file);
  formData.append('project_id', projectId);

  const response = await fetch('/api/upload/document', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${token}`
    },
    body: formData
  });

  return await response.json();
}

// 載入語系檔案
async function loadLocale(lang) {
  const response = await fetch(`/locales/${lang}/common.json`);
  return await response.json();
}
```
