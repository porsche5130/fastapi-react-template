## 選擇理由

### FastAPI
- 現代化的 Python Web 框架
- 自動生成 OpenAPI 文件
- 內建資料驗證（Pydantic）
- 高效能（基於 Starlette 和 uvicorn）
- 原生支援非同步

### PostgreSQL + JSONB
- 成熟穩定的關係型資料庫
- JSONB 支援靈活的 PDD 表單資料結構（585 段落、149 表格）
- 完整的 ACID 支援
- 豐富的 JSON 查詢功能

### Redis
- 高效能的記憶體快取
- 支援多種資料結構
- 適合 Session 管理和 API 快取

### SQLAlchemy 2.0
- Python 最成熟的 ORM
- 2.0 版本全面支援非同步
- 類型提示完整

### JWT
- 無狀態認證，適合分散式系統
- 不需要伺服器端 Session 儲存
- 支援跨域認證

## 安裝說明

### requirements.txt

```txt
# 核心框架
fastapi==0.109.0
uvicorn[standard]==0.27.0
pydantic==2.5.0
pydantic-settings==2.1.0

# 資料庫
sqlalchemy==2.0.25
alembic==1.13.1
psycopg2-binary==2.9.9
redis==5.0.1

# 身份驗證
python-jose[cryptography]==3.3.0
passlib[bcrypt]==1.7.4

# HTTP & 檔案
httpx==0.26.0
python-multipart==0.0.6

# 工具
python-dotenv==1.0.0

# 測試
pytest==7.4.4
pytest-asyncio==0.23.3
pytest-cov==4.1.0

# 程式碼品質
black==23.12.1
flake8==7.0.0
mypy==1.8.0
isort==5.13.2
```

### 安裝指令

```bash
# 安裝 Python 套件
pip install -r requirements.txt

# PostgreSQL 和 Redis 需本機安裝
# 參考文件：W:\P-PA6.4\系統設計\架構設計\開發環境\開發測試環境.md
```
