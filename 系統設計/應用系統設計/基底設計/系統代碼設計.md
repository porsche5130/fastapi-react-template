# 系統代碼設計

## 概述

系統代碼明細檔（system_codes）用於儲存系統中各類代碼資料，支援中英文雙語顯示及 HTML 渲染功能。

## 資料結構

### 資料表：system_codes

| 欄位名稱 | 資料型別 | 長度 | 約束 | 說明 |
|---------|---------|------|------|------|
| id | INTEGER | 8 | PK, AUTO_INCREMENT | 資料編號 |
| code_etype | VARCHAR | 100 | NOT NULL, INDEX | 代碼類別英文名稱 |
| code_ctype | VARCHAR | 200 | NOT NULL, INDEX | 代碼類別中文名稱 |
| code | VARCHAR | 50 | NOT NULL, INDEX | 代碼編號 |
| code_cname | VARCHAR | 300 | NOT NULL | 代碼中文名稱 |
| code_ename | VARCHAR | 300 | NULL | 代碼英文名稱 |
| order | INTEGER | 4 | NOT NULL, DEFAULT 0, INDEX | 次序 |
| is_active | BOOLEAN | - | NOT NULL, DEFAULT TRUE, INDEX | 啟用狀態 |
| note1 | VARCHAR | 500 | NULL | 說明1 |
| note2 | VARCHAR | 500 | NULL | 說明2 |
| note3 | VARCHAR | 500 | NULL | 說明3 |
| note4 | VARCHAR | 500 | NULL | 說明4 |
| note5 | VARCHAR | 500 | NULL | 說明5 |
| edit_by | INTEGER | 8 | NOT NULL, FK(user_detail.id) | 資料建立/修改人員 |
| created_at | TIMESTAMP | - | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 資料建立時間 |
| updated_at | TIMESTAMP | - | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 資料最新修改時間 |

### 索引

- `idx_system_codes_type`: (code_etype, code_ctype)
- `idx_system_codes_code`: (code)
- `idx_system_codes_active`: (is_active)
- `idx_system_codes_order`: (order)

## 功能說明

### 1. CRUD DataTables

#### 顯示欄位
1. **ID** (資料編號) - 可排序
2. **[代碼類別]** (code_etype, code_ctype) - 可排序
   - 中文語系：中文名稱(英文名稱)
   - 英文語系：英文名稱(中文名稱)
   - 次要文字小 2 個字級，灰色顯示
3. **代碼編號** (code)
4. **[代碼名稱]** (code_cname, code_ename)
   - 中文語系：中文名稱(英文名稱)
   - 英文語系：英文名稱(中文名稱)
   - 次要文字小 2 個字級，灰色顯示
5. **次序** (order) - 可排序
6. **狀態** (is_active) - 可點擊切換
7. **操作** (Actions)
   - 檢視（View）
   - 編輯（Edit）- 需要 update 權限
   - 刪除（Delete）- 需要 delete 權限

### 2. HTML 渲染支援

所有文字欄位（code_etype, code_ctype, code, code_cname, code_ename）皆支援 HTML 渲染，允許使用以下標籤：

- `<sup>上標</sup>` - 上標文字
- `<sub>下標</sub>` - 下標文字

範例：
- CO<sub>2</sub> → CO₂
- X<sup>2</sup> → X²

### 3. 篩選功能

提供三個**下拉選單**篩選欄位，實時篩選資料：

1. **代碼類別**（下拉選單）
   - 顯示所有唯一的代碼類別組合
   - 中文語系：顯示「中文名稱 (英文名稱)」
   - 英文語系：顯示「英文名稱 (中文名稱)」
   - 精確匹配選擇的類別

2. **代碼編號**（下拉選單）
   - 顯示所有唯一的代碼編號
   - 精確匹配選擇的代碼

3. **代碼名稱**（下拉選單）
   - 顯示所有唯一的代碼名稱組合
   - 中文語系：顯示「中文名稱 (英文名稱)」
   - 英文語系：顯示「英文名稱 (中文名稱)」
   - 精確匹配選擇的名稱

**重置功能**：點擊「重置」按鈕可清除所有篩選條件並恢復預設排序

### 4. 排序功能

支援以下欄位排序（點擊表頭切換升降冪）：

1. **ID** (資料編號)
2. **代碼類別** (code_etype + code_ctype)
3. **次序** (order)

### 5. 狀態切換

- 點擊「啟用」或「停用」狀態標籤可直接切換
- 需要 update 權限
- 自動記錄使用者日誌

### 6. I18N 國際化

支援語系切換（zh-TW / en）：

- 頁面標題：從 sysfunction 動態載入
- 所有介面文字：使用 i18n translation keys
- 代碼顯示：依語系自動切換主次顯示

### 7. 使用者日誌

依照「使用者日誌設計.md」規則記錄：

- **View**: 頁面開啟
- **Create**: 新增代碼
- **Read**: 檢視代碼詳情
- **Update**: 修改代碼（包含狀態切換）
- **Delete**: 刪除代碼

## API 端點

### 基礎 CRUD

- `GET /api/system_codes` - 查詢系統代碼列表
- `GET /api/system_codes/{code_id}` - 查詢單一系統代碼
- `POST /api/system_codes` - 建立系統代碼
- `PUT /api/system_codes/{code_id}` - 更新系統代碼
- `DELETE /api/system_codes/{code_id}` - 刪除系統代碼

### 特殊查詢

- `GET /api/system_codes/type/{code_etype}` - 根據代碼類別查詢
  - 參數：
    - `code_ctype` (optional): 代碼類別中文名稱
    - `active_only` (default: true): 只查詢啟用的代碼

### 查詢參數

所有查詢支援以下參數：

- `code_etype`: 代碼類別英文名稱（模糊搜尋）
- `code_ctype`: 代碼類別中文名稱（模糊搜尋）
- `code`: 代碼編號（模糊搜尋）
- `code_cname`: 代碼中文名稱（模糊搜尋）
- `code_ename`: 代碼英文名稱（模糊搜尋）
- `is_active`: 啟用狀態
- `search`: 綜合搜尋（代碼類別、代碼編號、代碼名稱）

## 使用範例

### 新增代碼範例

```json
{
  "code_etype": "GHG_TYPE",
  "code_ctype": "溫室氣體類型",
  "code": "CO2",
  "code_cname": "二氧化碳 (CO<sub>2</sub>)",
  "code_ename": "Carbon Dioxide (CO<sub>2</sub>)",
  "order": 1,
  "is_active": true,
  "note1": "全球暖化潛勢 GWP = 1"
}
```

### 查詢特定類別代碼

```javascript
const ghgCodes = await getSystemCodesByType('GHG_TYPE', '溫室氣體類型', true);
```

## 注意事項

1. **HTML 安全性**：只允許 `<sub>` 和 `<sup>` 標籤，其他 HTML 標籤會被轉義
2. **排序優先順序**：預設依 ID 升冪排序，可點擊表頭切換
3. **狀態切換**：點擊狀態標籤時需要 update 權限，否則無法切換
4. **欄位長度**：請注意各欄位最大長度限制
5. **必填欄位**：code_etype, code_ctype, code, code_cname 為必填
6. **篩選方式**：使用下拉選單精確篩選，非模糊搜尋
7. **下拉選項**：篩選下拉選單選項依當前語系動態生成
