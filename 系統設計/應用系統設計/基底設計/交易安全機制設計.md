## 核心理念

### 設計原則 (v3.0)

> **一個 Session，一個 Token，包含所有權限**
>
> 登入時同時建立 Session 和 Transaction Token，Token 包含使用者對**所有功能**的權限資訊。

### 關鍵概念

1. **統一的 Transaction Token**
   - 一個 Session 只有一個 Token
   - Token 包含使用者所有功能的權限
   - Token 有效期 30 分鐘，每次使用自動延長 30 分鐘
   - Session 有效期 60 分鐘，每次使用自動延長 30 分鐘

2. **雙重驗證機制**
   - **Session ID** (60分鐘): 掌握使用者基本資訊
   - **Transaction Token** (30分鐘): 綁定所有功能權限

3. **三層安全防護**
   - **第一層**: JWT Token 解析出 session_id
   - **第二層**: Redis Session 驗證 (session_id 存在且有效)
   - **第三層**: Redis Token 驗證 (token 存在、session_id 匹配、有功能權限)

## 架構總覽

### 登入流程

```
POST /api/auth/login
    ↓
1. 驗證帳號密碼 (查詢資料庫)
    ↓
2. 查詢使用者角色權限 (查詢 role_rights + system_functions)
    ↓
3. 建立 Session (Redis, 60分鐘)
   {
       "user_id": 1,
       "organization_id": 5,
       "role_ids": [1, 2],
       "username": "張三",
       "account": "user001",
       "authorized_function_ids": [1, 5, 10, ...]
   }
    ↓
4. 建立 Transaction Token (Redis, 30分鐘)
   {
       "session_id": "uuid",
       "permissions": {
           "1": {  // system_function_id
               "func_code": "organizations",
               "module_code": "organizations",
               "create": true,
               "read": true,
               "update": true,
               "delete": false,
               "print": false,
               "file": false
           },
           "5": {...}
       }
   }
    ↓
5. 回傳給前端
   {
       "access_token": "JWT(session_id)",
       "token_type": "bearer",
       "txn_token": "交易令牌"
   }
```

### API 請求流程

```
前端呼叫 API
Headers:
  Authorization: Bearer {JWT_TOKEN}
  X-Txn-Token: {TRANSACTION_TOKEN}
    ↓
1. 從 JWT 取得 session_id
    ↓
2. 查詢 Redis Session
   - 不存在 → 401 請重新登入
   - 存在 → 延長 30 分鐘
    ↓
3. 驗證 Transaction Token
   - Token 不存在 → 401 Token 已過期
   - session_id 不匹配 → 403 Token 與 Session 不符
   - 沒有該功能權限 → 403 無權限
   - 驗證通過 → 延長 30 分鐘
    ↓
4. 執行業務邏輯
```

### Token 過期處理

```
情境：30 分鐘後 Token 過期
前端：收到 401 "Token 已過期"
    ↓
前端自動呼叫：POST /api/transaction/refresh
Headers: Authorization: Bearer {JWT_TOKEN}
    ↓
後端：
1. 驗證 Session 是否有效
   - Session 過期 → 401 請重新登入
   - Session 有效 → 繼續
    ↓
2. 重新查詢資料庫權限
    ↓
3. 建立新的 Token (30分鐘)
    ↓
4. 回傳新的 txn_token
    ↓
前端：
1. 更新 localStorage 中的 txn_token
2. 重試原本失敗的請求
```

## API 端點規範

### 重要規則

1. ✅ **所有功能操作端點都需要 Token**
2. ✅ **初始化端點不需要 Token** (僅需 Bearer Token)
   - `/api/system_functions/tree` - 選單
   - `/api/system_functions/` - 功能列表
   - `/api/organizations/{id}` - 組織資訊
   - `/api/sys_profiles/` - 系統設定
3. ✅ **GET → read 權限**
4. ✅ **POST → create 權限**
5. ✅ **PUT/PATCH → update 權限**
6. ✅ **DELETE → delete 權限**
7. ❌ **不要再使用 `check_permission` 手動檢查**
8. ✅ **所有 API 文件都要說明需要的權限**

### GET 端點範例 (查詢) - 需要 read 權限

```python
@router.get("/", response_model=List[UserRoleResponse])
async def get_user_roles(
    skip: int = 0,
    limit: int = 100,
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user),
    _token: None = Depends(require_txn_token("user_roles", "read"))
):
    """
    取得使用者角色列表

    需要 user_roles 功能的 read 權限
    需要提供 Bearer Token 及 X-Txn-Token Header
    """
    # Token 已驗證權限，直接執行業務邏輯
    query = db.query(UserRole)
    roles = query.order_by(UserRole.id).offset(skip).limit(limit).all()
    return roles
```

### POST 端點範例 (新增) - 需要 create 權限

    db: Session = Depends(get_db),

    _token: None = Depends(require_txn_token("user_roles", "create"))
):
    """
    建立使用者角色

    需要 user_roles 功能的 create 權限
    需要提供 Bearer Token 及 X-Txn-Token Header
    """
    # Token 已驗證權限，不需要再次檢查
    role = UserRole(**role_data.model_dump(), edit_by=current_user.id)

## 錯誤處理

| HTTP Status | 錯誤情境 | 說明 | 前端處理 |
|-------------|---------|------|---------|
| 401 Unauthorized | Session 過期 | Session 已過期 | 跳轉登入頁 |
| 401 Unauthorized | Token 過期 | Token 已過期，Session 有效 | 自動刷新 Token |
| 401 Unauthorized | Token 無效 | Token 格式錯誤 | 跳轉登入頁 |
| 403 Forbidden | 無功能權限 | 沒有該功能的任何權限 | 顯示無權限訊息 |
| 403 Forbidden | 無操作權限 | Token 有效但缺少該操作權限 | 隱藏操作按鈕 |
| 403 Forbidden | Session 不符 | Token 與當前 Session 不符 | 跳轉登入頁 |
| 404 Not Found | 功能不存在 | 系統功能未註冊 | 顯示錯誤訊息 |

## 安全考量

### Token 安全
- ✅ **綁定 Session**: Token 與 session_id 綁定，無法跨 Session 使用
- ✅ **有效期限制**: Token 30 分鐘，Session 60 分鐘
- ✅ **自動延長**: 每次使用延長 30 分鐘，保持活躍
- ✅ **SHA256 雜湊**: Token 使用 SHA256 產生，無法預測
- ✅ **Redis 儲存**: 使用 Redis TTL 自動清理過期 Token

### 權限安全
- ✅ **最小權限原則**: 使用者只能取得 role_rights 中定義的權限
- ✅ **權限快照**: Token 建立時快照權限，30 分鐘內不變
- ✅ **禁止權限提升**: Token 中的權限不可修改或偽造
- ✅ **角色變更即時生效**: Token 過期後重新查詢資料庫

### 防止攻擊
- ✅ **CSRF 防護**: Token 存在 Header (X-Txn-Token)，非 Cookie
- ✅ **XSS 防護**: Token 存在 localStorage，需配合 CSP 政策
- ✅ **Session 劫持防護**: Token 與 Session 雙重綁定
- ✅ **暴力破解**: Token 使用強雜湊，無法暴力破解

### 效能優化
- ✅ **登入時查詢一次資料庫**: 建立 Session + Token
- ✅ **API 請求只查 Redis**: 99% 的請求不碰資料庫
- ✅ **Token 刷新時查詢一次**: 30 分鐘刷新一次權限
- ✅ **Session 自動延長**: 活躍使用者不會被登出

### 登入後儲存 Token

const response = await api.post('/api/auth/login', {

### axios 請求攔截器 - 自動添加 Token

```javascript
// 建立 axios 實例
const axiosInstance = axios.create({
  baseURL: API_BASE_URL,
  timeout: 10000,
  headers: {
    'Content-Type': 'application/json',
  },
});

// 請求攔截器 - 自動加入 Token
axiosInstance.interceptors.request.use(
  (config) => {
    // 添加 Bearer Token (JWT / session_id)
    const token = localStorage.getItem('session_id') || localStorage.getItem('access_token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }

    // 添加 Transaction Token (從 localStorage 自動讀取)
    const txnToken = localStorage.getItem('txn_token');
    if (txnToken && !config.headers['X-Txn-Token']) {
      config.headers['X-Txn-Token'] = txnToken;
    }

    return config;
  },
  (error) => {
    return Promise.reject(error);
  }
);
```

### axios 回應攔截器 - 自動處理 Token 過期

```javascript
// 是否正在重新整理 token 的旗標
let isRefreshing = false;
// 等待 token 重新整理完成的請求佇列
let failedQueue = [];

// 處理等待佇列
const processQueue = (error = null, token = null) => {
  failedQueue.forEach((prom) => {
    if (error) {
      prom.reject(error);
    } else {
      prom.resolve(token);
    }
  });
  failedQueue = [];
};

// 回應攔截器 - 處理錯誤與自動重新申請 token
axiosInstance.interceptors.response.use(
  (response) => {
    return response;
  },
  async (error) => {
    const originalRequest = error.config;

    if (error.response) {
      // 401 未授權 - 可能是 token 過期
      if (error.response.status === 401) {
        const errorDetail = error.response.data?.detail || '';

        // 判斷是否為 token 過期 (但 session 仍有效)
        if (errorDetail.includes('交易令牌無效或已過期') && !originalRequest._retry) {
          originalRequest._retry = true;

          // 如果正在重新整理 token,將此請求加入等待佇列
          if (isRefreshing) {
            return new Promise((resolve, reject) => {
              failedQueue.push({ resolve, reject });
            })
              .then(() => {
                // token 重新整理完成,重試原請求
                return axiosInstance(originalRequest);
              })
              .catch((err) => {
                return Promise.reject(err);
              });
          }

          isRefreshing = true;

          // 嘗試重新申請 token
          try {
            // 從 localStorage 取得 session_id
            const sessionId = localStorage.getItem('session_id') || localStorage.getItem('access_token');
            if (!sessionId) {
              throw new Error('無 session_id');
            }

            // 重新申請全域 token
            // 注意: 後端需要提供 POST /api/transaction/refresh API
            const response = await axios.post('/api/transaction/refresh', {}, {
              headers: { Authorization: `Bearer ${sessionId}` }
            });

            // 更新 localStorage 中的 token
            const newToken = response.data.txn_token;
            localStorage.setItem('txn_token', newToken);

            // 處理等待佇列
            processQueue(null, newToken);

            // 重試原請求
            return axiosInstance(originalRequest);
          } catch (refreshError) {
            // token 重新整理失敗,清除所有 token 並導向登入頁
            processQueue(refreshError, null);
            localStorage.removeItem('session_id');
            localStorage.removeItem('access_token');
            localStorage.removeItem('txn_token');
            window.location.href = '/login';
            return Promise.reject(refreshError);
          } finally {
            isRefreshing = false;
          }
        } else {
          // 其他 401 錯誤 (如 session 過期),直接導向登入頁
          localStorage.removeItem('session_id');
          localStorage.removeItem('access_token');
          localStorage.removeItem('txn_token');
          window.location.href = '/login';
        }
      }
      // 403 禁止存取
      else if (error.response.status === 403) {
        console.error('禁止存取:', error.response.data.detail);
      }
    }
    return Promise.reject(error);
  }
);

export default axiosInstance;
```

### 頁面初始化 - 從 localStorage 讀取 Token

```javascript
// 功能頁面元件
const ExamplePage: React.FC = () => {
  const [txnToken, setTxnToken] = useState<string>('');
  const [permissions, setPermissions] = useState({});

  useEffect(() => {
    const initPage = async () => {
      try {
        // 從 localStorage 讀取登入時的全域 txn_token
        const storedToken = localStorage.getItem('txn_token');

        if (!storedToken) {
          throw new Error('未找到交易令牌，請重新登入');
        }

        setTxnToken(storedToken);
        // 假設有完整權限 (實際權限由後端 token 內容決定)
        setPermissions({
          create: true,
          read: true,
          update: true,
          delete: true,
        });

        // 載入資料 (axios 攔截器會自動添加 txn_token)
        await loadData();
      } catch (error) {
        console.error('Init page failed:', error);
        alert('載入失敗');
      }
    };

    initPage();
  }, []);

  const loadData = async () => {
    // axios 攔截器會自動從 localStorage 讀取 txn_token 並添加到 header
    const response = await exampleService.getAll();
    setData(response.data);
  };

  return (
    // ... 頁面內容
  );
};
```
