## 1. 功能概述

### 1.1 功能說明
角色權限設定作業提供系統管理員為不同角色配置功能存取權限的介面。管理員可以選擇特定角色，並針對系統中每個已啟用的功能，設定該角色是否擁有新增、讀取、修改、刪除、列印、產檔等操作權限。

### 1.2 業務目標
- 實現彈性的角色權限管理機制
- 支援細粒度的功能操作權限控制
- 確保權限設定的一致性與正確性
- 提供直觀的權限配置介面

### 1.3 使用者角色
- **系統管理員**: 具有設定所有角色權限的能力
- **一般管理員**: 可能受限於特定角色的權限設定

### 1.4 功能選單顯示規則

**規則更新日期**: 2026-01-19

系統功能選單(`/api/system/functions`)依據使用者角色權限動態顯示,遵循以下規則:

#### 1.4.1 權限檢查邏輯
1. **讀取權限要求**: 功能必須具備「讀取」權限(`is_read = true`)才會顯示在選單中
2. **多角色聯集**: 使用者如有多個角色,採用聯集(OR)邏輯 - 任一角色擁有讀取權限即可顯示
3. **權限查詢來源**: 從 `role_right` 表查詢使用者所屬角色的權限設定

#### 1.4.2 節點過濾規則
1. **空節點隱藏**: 若節點(`func_type = 1`)下沒有任何可顯示的子功能,則該節點不顯示
2. **遞迴檢查**: 系統會遞迴檢查整個功能樹,確保每個顯示的節點下至少有一個可用功能
3. **保持結構**: 保留原有的樹狀階層結構,不改變 func_order 排序

#### 1.4.3 實作位置
- **後端 API**: `app/routes/system.py` - `get_system_functions()`
- **前端元件**: `src/components/Sidebar.tsx` - 直接使用過濾後的功能清單

#### 1.4.4 範例說明

假設使用者具有以下角色權限:
- 系統管理後台(節點) → 不需權限,自動包含
  - 系統設定資料 → 有讀取權限 ✓
  - 組織設定 → 有讀取權限 ✓
  - 角色權限設定 → 無讀取權限 ✗

結果: 選單顯示「系統管理後台」節點,下方包含「系統設定資料」和「組織設定」兩個功能

假設使用者角色權限:
- 專案活動管理(節點) → 不需權限
  - 子功能 A → 無讀取權限 ✗
  - 子功能 B → 無讀取權限 ✗

結果: 「專案活動管理」節點整個隱藏,因為下方沒有任何可用功能

## 2. 功能需求

### 2.1 核心功能流程

```
開始
  ↓
選擇角色 (user_role.is_active = true)
  ↓
查詢該角色的現有權限設定
  ↓
├─ 有設定 → 顯示現有權限供修改
└─ 無設定 → 顯示空白權限供新增
  ↓
載入所有已啟用功能 (sysfuction.is_active = true)
  ↓
依 func_order 排序顯示功能樹狀結構
  ↓
針對每個功能顯示權限勾選框
├─ 功能的 module_item 包含該權限 → 啟用勾選框
└─ 功能的 module_item 不包含該權限 → 禁用勾選框 (預設 false)
  ↓
使用者調整權限設定
  ↓
點擊儲存
  ↓
刪除該角色的所有舊權限資料
  ↓
批次新增最新的權限設定資料
  ↓
完成
```

### 2.2 詳細功能需求

#### 2.2.1 角色選擇
- 下拉選單顯示所有啟用的角色 (`user_role.is_active = true`)
- 顯示格式: `{role_cname} ({role_ename})`
- 選擇角色後自動載入權限設定

#### 2.2.2 權限資料載入
1. **查詢現有權限**:
   ```sql
   SELECT * FROM role_right
   WHERE user_role_id = {selected_role_id}
   ```

2. **載入功能清單**:
   ```sql
   SELECT * FROM sysfuction
   WHERE is_active = true
   ORDER BY func_order ASC
   ```

3. **建立權限矩陣**:
   - 橫軸: 功能清單 (依 func_order 排序)
   - 縱軸: 權限類型 (Create, Read, Update, Delete, Print, File)

#### 2.2.3 權限設定介面

**介面結構**:
```
┌─────────────────────────────────────────────────────────────┐
│ 角色權限設定作業                                             │
├─────────────────────────────────────────────────────────────┤
│ 選擇角色: [系統管理員 (System Administrator) ▼]              │
├─────────────────────────────────────────────────────────────┤
│ 功能名稱              │新增│讀取│修改│刪除│列印│產檔│         │
├─────────────────────────────────────────────────────────────┤
```

**圖例說明**:
- `☑`: 已啟用且已勾選
- `☐`: 已啟用但未勾選
- `-`: 該功能不支援此權限 (disabled)

#### 2.2.4 權限勾選框邏輯

針對每個功能的每個權限類型:

1. **新增權限 (Create)**:
   - 檢查: `sysfuction.module_item` 是否包含 `"Create"`
   - 包含 → 啟用勾選框，可由使用者設定
   - 不包含 → 禁用勾選框，`is_create = false`

2. **讀取權限 (Read)**:
   - 檢查: `sysfuction.module_item` 是否包含 `"Read"`
   - 包含 → 啟用勾選框，可由使用者設定
   - 不包含 → 禁用勾選框，`is_read = false`

3. **修改權限 (Update)**:
   - 檢查: `sysfuction.module_item` 是否包含 `"Update"`
   - 包含 → 啟用勾選框，可由使用者設定
   - 不包含 → 禁用勾選框，`is_update = false`

4. **刪除權限 (Delete)**:
   - 檢查: `sysfuction.module_item` 是否包含 `"Delete"`
   - 包含 → 啟用勾選框，可由使用者設定
   - 不包含 → 禁用勾選框，`is_delete = false`

5. **列印權限 (Print)**:
   - 檢查: `sysfuction.module_item` 是否包含 `"Print"`
   - 包含 → 啟用勾選框，可由使用者設定
   - 不包含 → 禁用勾選框，`is_print = false`

6. **產檔權限 (File)**:
   - 檢查: `sysfuction.module_item` 是否包含 `"File"`
   - 包含 → 啟用勾選框，可由使用者設定
   - 不包含 → 禁用勾選框，`is_file = false`

#### 2.2.5 儲存邏輯

**重要**: 為避免資料誤植，採用「先刪後增」策略

```python
def save_role_rights(user_role_id: int, rights_data: List[RoleRightData]):
    """
    儲存角色權限設定

    步驟:
    1. 開始資料庫交易
    2. 刪除該角色的所有現有權限
    3. 批次新增最新的權限設定
    4. 提交交易
    """
    try:
        # 1. 刪除舊資料
        db.query(RoleRight).filter(
            RoleRight.user_role_id == user_role_id
        ).delete()

        # 2. 批次新增新資料
        new_rights = []
        for right in rights_data:
            new_right = RoleRight(
                user_role_id=user_role_id,
                sysfuction_id=right.sysfuction_id,
                func_code=right.func_code,
                is_create=right.is_create,
                is_read=right.is_read,
                is_update=right.is_update,
                is_delete=right.is_delete,
                is_print=right.is_print,
                is_file=right.is_file,
                edit_by=current_user.id,
                created_at=datetime.now()
            )
            new_rights.append(new_right)

        db.bulk_save_objects(new_rights)
        db.commit()

        return {"message": "權限設定儲存成功"}
    except Exception as e:
        db.rollback()
        raise HTTPException(status_code=500, detail=f"儲存失敗: {str(e)}")
```

## 3. 資料庫設計

### 3.1 資料表結構

```sql
-- 角色權限設定檔
CREATE TABLE IF NOT EXISTS role_right (
    -- 主鍵
    id SERIAL PRIMARY KEY,

    -- 關聯欄位
    user_role_id INTEGER NOT NULL,
    sysfuction_id INTEGER NOT NULL,
    func_code VARCHAR(20) NOT NULL,

    -- 權限設定
    is_create BOOLEAN NOT NULL DEFAULT FALSE,
    is_read BOOLEAN NOT NULL DEFAULT FALSE,
    is_update BOOLEAN NOT NULL DEFAULT FALSE,
    is_delete BOOLEAN NOT NULL DEFAULT FALSE,
```

| 欄位名稱 | 資料型態 | 長度 | 約束 | 說明 |

| sysfuction_id | INTEGER | - | NOT NULL, FK | 功能編號 (參考 sysfuction.id) |

| is_update | BOOLEAN | - | NOT NULL, DEFAULT FALSE | 修改權限 |
| is_delete | BOOLEAN | - | NOT NULL, DEFAULT FALSE | 刪除權限 |
| is_print | BOOLEAN | - | NOT NULL, DEFAULT FALSE | 列印權限 |
| is_file | BOOLEAN | - | NOT NULL, DEFAULT FALSE | 檔案權限 |

| updated_at | TIMESTAMP | - | NULL | 資料修改時間 |

### 3.3 約束說明

1. **主鍵約束**: `id` 為主鍵，自動遞增
2. **外鍵約束**:
   - `user_role_id` → `user_role(id)` - CASCADE DELETE
   - `sysfuction_id` → `sysfuction(id)` - CASCADE DELETE
   - `edit_by` → `user_detail(id)`
3. **唯一性約束**: `(user_role_id, sysfuction_id)` 組合唯一，確保一個角色對一個功能只有一組權限設定
4. **預設值**: 所有權限欄位預設為 `FALSE` (無權限)

## 5. 後端實作

### 5.1 資料模型 (Model)

**檔案**: `app/models/role_right.py`

```python
"""
Role Right Model
角色權限設定檔
"""

from sqlalchemy import Column, Integer, String, Boolean, TIMESTAMP, ForeignKey, Index
from sqlalchemy.orm import relationship
from sqlalchemy.sql import func
from app.core.database import Base


class RoleRight(Base):
    """角色權限設定檔"""

    __tablename__ = "role_right"

    # 主鍵
    id = Column(Integer, primary_key=True, index=True)

    # 關聯欄位
    user_role_id = Column(Integer, ForeignKey("user_role.id", ondelete="CASCADE"), nullable=False, index=True)
    sysfuction_id = Column(Integer, ForeignKey("sysfuction.id", ondelete="CASCADE"), nullable=False, index=True)
    func_code = Column(String(20), nullable=False)

    # 權限設定
    is_create = Column(Boolean, nullable=False, default=False)
    is_read = Column(Boolean, nullable=False, default=False)
    is_update = Column(Boolean, nullable=False, default=False)
    is_delete = Column(Boolean, nullable=False, default=False)
    is_print = Column(Boolean, nullable=False, default=False)
    is_file = Column(Boolean, nullable=False, default=False)

    # 系統欄位
    edit_by = Column(Integer, ForeignKey("user_detail.id"), nullable=False)
    created_at = Column(TIMESTAMP, nullable=False, server_default=func.current_timestamp())
    updated_at = Column(TIMESTAMP)

    # 索引與約束
    __table_args__ = (
        Index("idx_role_right_role", "user_role_id"),
        Index("idx_role_right_function", "sysfuction_id"),
        Index("idx_role_right_unique", "user_role_id", "sysfuction_id", unique=True),
    )

    # 關聯
    role = relationship("UserRole", foreign_keys=[user_role_id])
    function = relationship("SysFunction", foreign_keys=[sysfuction_id])
    editor = relationship("UserDetail", foreign_keys=[edit_by])
```

```python
@router.get("/{role_id}", response_model=RoleRightsDetail, summary="取得角色權限設定")

    role_id: int,
    db: Session = Depends(get_db),
    current_user: UserDetail = Depends(get_current_user)
):
    """取得指定角色的權限設定"""
    # 檢查角色是否存在
    role = db.query(UserRole).filter(UserRole.id == role_id).first()
    if not role:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="找不到指定的角色")

    # 查詢權限設定
    rights = db.query(RoleRight).filter(RoleRight.user_role_id == role_id).all()

    return RoleRightsDetail(

        role_name=role.role_cname,
        rights=rights

@router.post("/{role_id}", response_model=dict, summary="儲存角色權限設定")
async def save_role_rights(
    role_id: int,
    data: RoleRightBatchCreate,
    db: Session = Depends(get_db),
    current_user: UserDetail = Depends(get_current_user)
):
    """
    儲存角色權限設定 (先刪後增)

    步驟:
    1. 檢查角色是否存在且啟用
    2. 刪除該角色的所有現有權限
    3. 批次新增最新的權限設定
    """
    # 檢查角色
    role = db.query(UserRole).filter(UserRole.id == role_id).first()
    if not role:
        raise HTTPException(status_code=status.HTTP_404_NOT_FOUND, detail="找不到指定的角色")

    if not role.is_active:
        raise HTTPException(status_code=status.HTTP_409_CONFLICT, detail="該角色已停用，無法設定權限")

    try:
        # 1. 刪除舊資料
        deleted_count = db.query(RoleRight).filter(
            RoleRight.user_role_id == role_id
        ).delete()

        # 2. 批次新增新資料
        new_rights = []
        for right in data.rights:
            # 驗證功能是否存在
            function = db.query(SysFunction).filter(SysFunction.id == right.sysfuction_id).first()
            if not function:
                raise HTTPException(
                    status_code=status.HTTP_404_NOT_FOUND,
                    detail=f"找不到功能ID: {right.sysfuction_id}"
                )

            new_right = RoleRight(
                user_role_id=role_id,
                sysfuction_id=right.sysfuction_id,
                func_code=right.func_code,
                is_create=right.is_create,
                is_read=right.is_read,
                is_update=right.is_update,
                is_delete=right.is_delete,
                is_print=right.is_print,
                is_file=right.is_file,
                edit_by=current_user.id
            )
            new_rights.append(new_right)

        db.bulk_save_objects(new_rights)
        db.commit()

        return {
            "message": "權限設定儲存成功",
            "role_id": role_id,
            "total_rights": len(new_rights),
            "deleted_count": deleted_count
        }

    except HTTPException:
        db.rollback()
        raise
    except Exception as e:
        db.rollback()
        raise HTTPException(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            detail=f"權限設定儲存失敗: {str(e)}"
        )


@router.delete("/{role_id}", status_code=status.HTTP_200_OK, summary="刪除角色權限設定")

    role_id: int,
    db: Session = Depends(get_db),
```

### 7.1 權限檢查函數

**檔案**: `app/core/permissions.py`

```python
"""
Permission Check
權限檢查工具
"""

from typing import List
from fastapi import HTTPException, status
from sqlalchemy.orm import Session

from app.models.role_right import RoleRight
from app.models.user_detail import UserDetail


def check_permission(
    db: Session,
    user: UserDetail,
    func_code: str,
    permission_type: str
) -> bool:
    """
    檢查使用者是否擁有特定功能的特定權限

    Args:
        db: 資料庫 Session
        user: 使用者物件
        func_code: 功能代碼
        permission_type: 權限類型 (create/read/update/delete/print/file)

    Returns:
        bool: 是否有權限
    """
    # 取得使用者的所有角色ID
    role_ids: List[int] = user.user_role if isinstance(user.user_role, list) else []

    if not role_ids:
        return False

    # 查詢該使用者的角色是否有此功能的權限
    permission_field = f"is_{permission_type.lower()}"

    rights = db.query(RoleRight).filter(
        RoleRight.user_role_id.in_(role_ids),
        RoleRight.func_code == func_code
    ).all()

    # 只要有任一角色擁有權限即可
    for right in rights:
        if getattr(right, permission_field, False):
            return True

    return False


def require_permission(func_code: str, permission_type: str):
    """
    權限檢查裝飾器

    使用範例:
    @router.post("/organizations")
    @require_permission("organizations", "create")
    async def create_organization(...):
        ...
    """
    def decorator(func):
        async def wrapper(*args, **kwargs):
            db: Session = kwargs.get('db')
            current_user: UserDetail = kwargs.get('current_user')

            if not db or not current_user:
                raise HTTPException(
                    status_code=status.HTTP_401_UNAUTHORIZED,
                    detail="未授權"
                )

            if not check_permission(db, current_user, func_code, permission_type):
                raise HTTPException(
                    status_code=status.HTTP_403_FORBIDDEN,
                    detail=f"無權限執行此操作: {func_code} - {permission_type}"
                )

            return await func(*args, **kwargs)

        return wrapper
    return decorator
```

## 9. 注意事項與最佳實踐

### 9.1 資料一致性
- **先刪後增策略**: 避免資料誤植，確保每次儲存都是完整替換
- **交易處理**: 所有資料庫操作必須在同一個交易中完成
- **唯一性約束**: `(user_role_id, sysfuction_id)` 組合唯一，防止重複設定

### 9.2 效能優化
- **批次新增**: 使用 `bulk_save_objects` 進行批次插入
- **索引優化**: 在外鍵欄位建立索引加速查詢
- **快取策略**: 可考慮將權限資料快取於 Redis

### 9.3 安全性考量
- **權限驗證**: 每個 API 操作都應進行權限檢查
- **角色隔離**: 一般使用者不應能設定管理員權限
- **審計日誌**: 記錄權限變更歷史於 userlogs

### 9.4 使用者體驗
- **視覺回饋**: 禁用的勾選框應有明顯的視覺區別
- **操作確認**: 儲存前應提示變更內容
- **錯誤提示**: 清楚說明失敗原因
